## What's new in v1.18.0
Your existing cards now work with Home Assistant Marketplace as well as HACS.

### Fixed
- Installed-component counts, unused-item detection and pending updates no longer silently show zero after migrating to Marketplace.
- Dismissals, country hides and Restore synchronize with the active store's New list, without changing unrelated items.
- Starting or unreadable stores show unavailable data, not an empty library or an all-clear message. Scans retry automatically while the store starts.

### Upgrade notes
- Existing sensor IDs, dashboard card types, service names, installation dates and review history stay unchanged. No dashboard migration is needed.
- Restart Home Assistant after updating, then refresh your dashboard to load all four updated cards.
- The monitor uses guarded private Marketplace interfaces checked against Home Assistant 2026.11.0. If those interfaces change, it reports unavailable rather than reading stale HACS files.

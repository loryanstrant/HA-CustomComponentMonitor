# Correct installation ages across clock changes — v1.17.3

## Fixed
- Installation ages no longer gain or lose a day across daylight-saving changes when the scanner falls back to filesystem dates without a saved date registry.
- The automated validation test that exposed this issue now passes, with regression coverage for clocks moving both forward and back.

## Upgrade notes
No configuration changes are needed. Existing installation dates and the v1.17.2 HACS dismissal and Restore behaviour are unchanged.
